## ⚡ Signals & Systems Course Project

in this project we generate histograms of images and interpret it. then we can take 2D Fourier transform and describe the output. we can even design some filters and masks. then we learn to apply these techniques on an image to change its background. the project has some small details which are Otsu’s method ,Gaussian filters and so on.
